### Regional Food & Wine Tourism in Australia

An interactive data visualisation developed for FIT3179 Data Visualisation 2

This project explores domestic food and wine tourism across Australia, focusing on visitor activity, regional tourism spending, wine regions and differences between selected destinations.

The visualisation was developed using HTML, CSS, JavaScript and Vega-Lite.
